## 3. AI Agent 生态

本周 Agent 生态的核心议题是 **从单代理向多代理/团队工作流系统演进** 过程中遇到的稳定性与治理挑战。

- **多代理协作**：Claude Code（`agent-creator` 技能）、OpenCode（`/goal` 功能请求）、Qwen Code 均收到大量关于多代理隔离、状态同步、任务分解可靠性的需求。社区普遍认为当前子代理行为不一致、崩溃恢复机制缺失是生产环境最大障碍。
- **配置与上下文可靠性**：项目级规则（如 `.mcp.json`、`CLAUDE.md`）在子代理或上下文压缩中失效的问题在 Claude Code 和 Qwen Code 社区被反复提及，要求支持关键配置豁免压缩。
- **资源与权限精细化**：实时 Token/上下文用量显示、会话级预算控制、运行时权限透明化（如 Claude Code 的权限被静默覆盖问题）成为企业采纳的“入场券”。
- **MCP 作为 Agent 互操作标准**：所有工具均将 MCP 作为扩展 Agent 能力、集成外部工具的核心协议，但其认证流程、服务器配置的易用性与稳定性是当前最大瓶颈。
